# Dryer Runs But Won't Heat / Clothes Stay Wet

## Symptoms covered

- Dryer tumbles but clothes don't dry (no heat or low heat)
- Dryer takes 2-3 cycles to dry a normal load
- Dryer gets very hot on the outside but clothes are still wet
- Dryer shuts off before the cycle completes
- Dryer runs normally but exhaust at the vent outside is weak or absent

Does NOT cover: dryer won't start at all (see KB-APPL-001), dryer making grinding/banging noises (dispatch directly, bearing or drum issue), dryer leaking water (condensate issue on ventless models, dispatch).

## Intake questions for tenant

1. Does the dryer tumble/run? (Drum spins, machine operates?)
2. Does it produce any heat at all, or is the air completely cold?
3. How long has this been happening? Gradual decline or sudden?
4. When did you last clean the lint trap?
5. Can you check the exterior vent termination? (Where the dryer exhaust exits the building.) Is air blowing out when the dryer runs? Is lint buildup visible?

**FIRE SAFETY CHECK**: If the dryer gets very hot on the outside, the exterior vent has weak or no airflow, or clothes take 2+ full cycles, this is likely a blocked vent. Dryer vent blockage is the leading cause of residential dryer fires. Classify as urgent regardless of other factors and dispatch.

## Diagnostic decision tree

```
START
│
├─ FIRE SAFETY check first:
│   ├─ Does the dryer get very hot on the OUTSIDE (top or back)?
│   ├─ Is exhaust at the exterior vent WEAK or ABSENT when dryer runs?
│   ├─ Does the laundry area get unusually hot or humid when dryer runs?
│   │   └─ If ANY of these → likely VENT BLOCKAGE. This is a FIRE HAZARD.
│   │       DISPATCH with urgency. Do not continue troubleshooting.
│   │       Tell tenant to stop using the dryer until the vent is cleared.
│   │       Vendor: dryer vent cleaning service.
│
├─ Clean the LINT TRAP
│   ├─ Pull out the lint screen. Is it caked with lint?
│   │   └─ Yes → clean thoroughly. Run a load.
│   │       └─ If it heats and dries → RESOLVED. Advise cleaning
│   │           before every load.
│   │       └─ Still no heat → continue
│   ├─ Even if it looks clean, wash the screen with soap and water.
│   │   (Dryer sheets leave a film that blocks airflow.)
│   │   Let it dry. Test again.
│
├─ Check the DRYER SETTINGS
│   ├─ Is it set to AIR DRY / AIR FLUFF? (No heat on this setting.)
│   │   └─ Switch to NORMAL, MEDIUM, or HIGH heat. Run a cycle.
│   │       └─ If it heats → RESOLVED (was on wrong setting)
│   ├─ Is it set to DELICATE or LOW? Some loads need MEDIUM or higher.
│
├─ Is it an ELECTRIC dryer? Check the breaker.
│   ├─ Electric dryers use a 240V double breaker. If ONE leg trips and
│   │   the other doesn't, the dryer will tumble but not heat (the motor
│   │   runs on 120V, the heating element needs 240V).
│   ├─ Check the dryer breaker. Is it tripped or does one side look off?
│   │   └─ Reset (flip both sides off, then on). Run a cycle.
│   │       └─ If it heats → RESOLVED (monitor for repeat trip)
│   │       └─ If breaker trips again → DISPATCH electrician
│
├─ Is it a GAS dryer? Check the gas supply.
│   ├─ Is there a gas shutoff valve behind the dryer?
│   │   (Usually a small lever on the gas line near the floor.)
│   │   └─ Is it in the ON position? (Lever parallel to pipe = on.)
│   │       └─ If off → turn on. Run a cycle.
│   │           └─ If it heats → RESOLVED
│   │       └─ If on and still no heat → DISPATCH. (Gas valve solenoid
│   │           or igniter failure. Not tenant-fixable.)
│   ├─ Can the tenant smell gas? → EMERGENCY. Stop. Advise tenant to
│   │   leave. Dispatch immediately.
│
├─ Is the dryer OVERLOADED?
│   ├─ Is the tenant trying to dry too much at once?
│   │   └─ Try a smaller load. If it dries → RESOLVED. Advise smaller loads.
│
├─ Does the dryer SHUT OFF before the cycle completes?
│   └─ Usually a thermal fuse or overheating issue (often vent-related).
│       ├─ Check vent for blockage (back to fire safety check above).
│       └─ If vent is clear and dryer still shuts off → DISPATCH.
│           Thermal fuse or thermostat replacement needed.
│
└─ If none of the above resolve → DISPATCH appliance repair tech.
```

## Tenant-fixable resolution steps

1. **Clean the lint trap**: Pull the screen out, remove all lint. Wash with soap and water to remove residue from dryer sheets. Let dry. Clean before every load going forward.

2. **Check dryer settings**: Make sure it's on a heated cycle (not AIR DRY or AIR FLUFF). Use MEDIUM or NORMAL for most loads.

3. **Check the breaker** (electric dryers): Find the double breaker for the dryer. Reset both sides (flip off, then on). A half-tripped double breaker allows tumbling but not heating.

4. **Check the gas valve** (gas dryers): Find the gas shutoff lever behind the dryer (near the floor). Make sure it's parallel to the gas pipe (on position).

5. **Reduce load size**: If cramming too much in, the dryer can't circulate hot air effectively. Try half the load.

## When to dispatch

- Vent blockage signs (hot exterior, weak exhaust, humid laundry area) → URGENT, fire hazard
- Electric breaker trips repeatedly
- Gas dryer with valve on but no heat (igniter/solenoid failure)
- Thermal fuse tripped (dryer shuts off mid-cycle, vent is clear)
- Lint trap clean, settings correct, breaker good, and still no heat
- Gas smell (Emergency)
- Tenant unable or unwilling to perform steps

## Vendor category to dispatch

Handyman or dryer vent cleaning service for vent blockage. Appliance repair technician for dryer mechanical issues (thermal fuse, igniter, heating element, gas valve solenoid). Handyman can also handle breaker diagnosis if the breaker keeps tripping. Licensed electrician only if there's a wiring issue beyond the breaker itself.

## Temporary mitigation while awaiting dispatch

- If vent blockage is suspected: tell tenant to STOP using the dryer until the vent is cleared. Use a laundromat or hang-dry in the interim. Continued use with a blocked vent is a fire risk.
- If mechanical (no heat but no safety concern): tenant can use a laundromat temporarily. The dryer isn't dangerous, it just won't dry.
- For electric dryers with a breaker issue: don't keep resetting the breaker. Leave it off and schedule the electrician.

## Tenant responsibility notes

Never tenant-responsible for mechanical failure (heating elements, thermal fuses, igniters, gas valve solenoids). Dryer vent cleaning responsibility varies by lease:
- Some leases require tenants to clean the lint trap (nearly all do this anyway)
- Some leases assign vent cleaning to the tenant (uncommon, check lease)
- Most PM companies treat vent cleaning as owner-responsible maintenance
- If the vent hasn't been cleaned in years and the owner never scheduled it, that's not the tenant's fault

## Work order fields to capture at dispatch

- Gas or electric dryer
- Symptoms (no heat, weak heat, shuts off early, vent concern)
- What was tried (lint trap, settings, breaker/gas valve)
- Whether there are fire hazard indicators (hot exterior, weak vent exhaust)
- Make/model if visible
- Whether the unit is stacked (affects access for repair)
- Tenant availability
- Location of the vent termination (roof, side wall) for vent cleaning access

## Suggested tenant communication

**Vent blockage (fire hazard)**: "Based on what you're describing, it sounds like the dryer vent may be blocked. I need you to stop using the dryer for now because a blocked vent is a fire hazard. I know that's inconvenient, but I'm getting a vent cleaning service out as quickly as possible. In the meantime, a laundromat or hang-drying are your best options."

**Mechanical (no heat, no safety concern)**: "Your dryer isn't dangerous, it's just not going to dry your clothes until we get it fixed. I'll schedule an appliance repair tech. It's probably a heating element or igniter. In the meantime, you're fine to tumble dry on air fluff to de-wrinkle, but for actual drying you'll need to hit a laundromat for a few days."

**After breaker fix resolves it**: "Looks like the breaker was the issue. Electric dryers use a special double breaker, and when half of it trips, the dryer tumbles but can't heat. Should be good to go now. If it happens again, let me know because that could mean an electrical issue."

## Notes for coordinator agent

- DRYER VENT BLOCKAGE IS A FIRE HAZARD. This is not a convenience issue. Lint buildup in dryer vents is the leading cause of residential laundry fires. If the symptoms suggest blockage, treat as urgent and tell the tenant to stop using the dryer.
- The electric dryer half-tripped breaker is one of the most commonly missed diagnoses. Coordinators and tenants often don't realize a double breaker can half-trip. Always check this for electric dryers with "tumbles but no heat."
- Dryer vent cleaning is recommended annually. If the property has never had it done, add it to the PM's preventative maintenance awareness (out of scope for v0.1 reactive maintenance, but worth noting).
- Standard repairs (vent cleaning, thermal fuse, heating element, gas valve solenoid) are all usually within NTE.
- For stacked washer/dryer units: the tech may need to separate them to access components. Note if stacked so the tech brings appropriate help/equipment.
- If the dryer is very old (15+ years) and the repair is a major component, replacement may be more economical. Flag for owner decision.
