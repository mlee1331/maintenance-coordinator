# Washing Machine Leaking, Not Draining, or Overflowing

## Symptoms covered

- Washer leaking water on the floor during a cycle
- Washer won't drain (water sits in the drum after cycle)
- Washer overflows
- Washer fills but won't agitate or spin
- Water backing up into the standpipe or laundry sink when washer drains

Does NOT cover: washer won't start at all (see KB-APPL-001), washer making loud banging during spin (bearing or suspension, dispatch directly), washer has a bad smell (cleaning issue, advise hot cycle with vinegar or washer cleaner).

## Intake questions for tenant

1. What's happening? Leaking, not draining, overflowing, or backing up?
2. Is there water on the floor right now? How much? [PHOTO]
3. Is the washer currently running or stopped?
4. If leaking: does it leak during fill, wash, or drain/spin cycle?
5. Is this a front-loader or top-loader?
6. Is it owner-provided or tenant-owned?

**Classification check**: If the washer is actively flooding (water continuing to flow onto the floor and tenant can't stop it), classify as urgent. Risk of water damage to flooring, subfloor, and any unit below.

If tenant-owned: not a maintenance issue. Advise them to contact appliance repair. Only dispatch if the leak is causing damage to the owner's property (flooring, unit below).

## Diagnostic decision tree

```
START
│
├─ Is it ACTIVELY FLOODING?
│   ├─ Turn off the washer. If it doesn't stop filling:
│   │   └─ Turn off the water supply valves behind the washer
│   │       (two valves, hot and cold, turn both clockwise).
│   │       └─ Water stops → contained. Clean up and continue diagnosis.
│   │       └─ Valves won't turn or water continues → DISPATCH urgently.
│   │           Turn off the main water supply if accessible.
│   └─ Place towels. Clean up water to prevent damage.
│
├─ Is it LEAKING (not flooding, but water on floor during use)?
│   ├─ WHEN does it leak?
│   │   ├─ During FILL → check supply hose connections at the back.
│   │   │   At Level 3+: are the hoses hand-tight where they connect to
│   │   │   the valves and the washer? Tighten gently. Run a cycle. Check.
│   │   │   └─ If dripping stops → RESOLVED
│   │   │   └─ If hoses look cracked, bulging, or corroded → DISPATCH
│   │   │       (hose replacement, flood risk if hose bursts)
│   │   ├─ During WASH → likely a door seal (front-loader) or tub seal.
│   │   │   Not tenant-fixable. DISPATCH.
│   │   ├─ During DRAIN/SPIN → check the drain hose connection.
│   │   │   Is the drain hose inserted into the standpipe properly?
│   │   │   (Should go in 6-8 inches, not be sealed tight.)
│   │   │   └─ If it fell out → reinsert. Run drain cycle. Test.
│   │   │       └─ If no more leak → RESOLVED
│   │   │   └─ If properly inserted and still leaking → check for
│   │   │       blockage (see drain section below). If clear → DISPATCH.
│   │   └─ During ALL phases → likely a tub or pump issue. DISPATCH.
│   ├─ [PHOTO] of where water appears on the floor in relation to the washer.
│
├─ Washer WON'T DRAIN (water sitting in drum)
│   ├─ Is there a drain filter? (Front-loaders have a small access panel
│   │   at the front bottom. Top-loaders sometimes have one too.)
│   │   └─ At Level 3+: place towels and a shallow pan. Open the filter
│   │       access. Remove the filter slowly (water will come out).
│   │       Clear any debris (coins, hair ties, socks, lint).
│   │       Replace filter. Run a drain cycle.
│   │       └─ If it drains → RESOLVED. Advise checking pockets before
│   │           washing.
│   │       └─ If still won't drain → DISPATCH
│   ├─ Is the drain hose kinked? (Check behind the washer.)
│   │   └─ If kinked → straighten. Run drain cycle.
│   │       └─ If it drains → RESOLVED
│   ├─ Is the standpipe (where the drain hose goes into the wall)
│   │   clogged? (Water backs up and overflows from the standpipe.)
│   │   └─ This is a plumbing issue, not a washer issue. See KB-PLUMB-003
│   │       for drain clogs. DISPATCH plumber to snake the standpipe.
│   └─ If none of the above → DISPATCH appliance repair (pump failure).
│
├─ Washer OVERFLOWS
│   ├─ Shut off washer immediately. If it continues filling → shut off
│   │   supply valves.
│   ├─ Overflow usually means: water level sensor failure, or drain is
│   │   blocked and water backs up.
│   ├─ Check: is water coming from the standpipe (drain backing up)?
│   │   └─ Yes → standpipe clog. DISPATCH plumber. Not a washer issue.
│   │   └─ No (washer itself overfilling) → DISPATCH appliance repair.
│   │       Water level sensor or fill valve failure.
│
├─ Water BACKS UP into laundry sink or standpipe
│   └─ This is a drain line clog, not a washer problem.
│       → DISPATCH plumber to snake the shared drain line.
│       The washer itself is fine.
│
└─ If none of the above resolve → DISPATCH appliance repair.
```

## Tenant-fixable resolution steps

1. **Shut off supply valves** (emergency): Turn both hot and cold valves behind the washer clockwise. Stops all water to the machine.

2. **Tighten supply hose connections** (Level 3+): Hand-tighten where hoses connect to the valves and to the washer. Don't over-tighten (can damage washers/gaskets).

3. **Reinsert drain hose**: Make sure it's properly inserted into the standpipe (6-8 inches deep, not sealed tight, with an air gap).

4. **Clear drain filter** (Level 3+, front-loaders): Open the access panel (front bottom). Place towels and a pan. Slowly open/remove the filter. Clear debris. Replace.

5. **Straighten kinked drain hose**: Check behind the washer for kinks or bends in the drain hose.

## When to dispatch

- Active flooding that tenant can't stop
- Supply hoses that are cracked, bulging, or corroded (flood risk)
- Door seal or tub seal leaking
- Won't drain after filter cleaning and hose check
- Overflow from the washer itself (not standpipe backup)
- Standpipe backup (dispatch plumber, not appliance tech)
- Pump failure (no drainage despite clear path)
- Tenant unable or unwilling to perform steps

## Vendor category to dispatch

Appliance repair technician for washer mechanical issues. Plumber for standpipe/drain line clogs. Check whether the issue is the washer or the building plumbing before dispatching.

## Temporary mitigation while awaiting dispatch

- Supply valves OFF if there's an active leak or flood risk
- Towels down, clean up standing water to prevent damage
- Don't use the washer until repaired (suggest laundromat)
- If hoses are bulging (burst risk): shut off valves immediately even if not currently leaking. Bulging = about to fail.
- If water reached flooring: prop open nearby cabinets and run fans to dry the area and prevent mold

## Tenant responsibility notes

Never tenant-responsible for mechanical failure of owner-provided washers. Drain clogs in the standpipe are always owner responsibility (building plumbing). If the tenant overloaded the machine or put something in it that caused damage, that's a grey area but still owner-coordinated for repair.

## Work order fields to capture at dispatch

- Nature of issue (leak, won't drain, overflow, backup)
- When it occurs (fill, wash, drain, all the time)
- Front-loader or top-loader
- Owner-provided or tenant-owned
- Whether supply valves were shut off
- Whether water reached flooring or unit below
- Photo of the water/leak location
- Whether the issue is the washer or the drain line (standpipe)
- Make/model if visible
- Tenant availability

## Suggested tenant communication

**Active flood**: "First, let's stop the water. Can you find the two supply valves behind the washer? Turn both of them clockwise to shut them off. Once the water stops, put towels down. I'll get someone out."

**Won't drain**: "Water sitting in the drum is annoying but it's not going to damage anything as long as it stays in there. I'll get an appliance tech scheduled. In the meantime, don't try to run it again."

**Standpipe backup**: "The water backing up isn't a washer problem. It's the drain line in the wall. I'm sending a plumber to clear it. Your washer is probably fine once the drain is clear."

## Notes for coordinator agent

- Always determine whether the issue is the WASHER or the BUILDING PLUMBING before dispatching. Standpipe backups and drain line clogs need a plumber. Washer mechanical issues need an appliance tech. Sending the wrong vendor wastes a trip.
- Supply hoses are the #1 source of catastrophic residential water damage. If the tenant mentions hoses that are old, bulging, cracked, or corroded, treat as urgent even if they're not leaking yet. A burst hose when no one is home can cause significant damage.
- Recommend braided stainless steel supply hoses (replace rubber hoses if old). Flag for PM as preventative upgrade.
- For multifamily: washer leaks on upper floors are urgent (damage to units below). Same urgency rules as KB-PLUMB-005.
- Old washers (10+ years) with pump or motor failure may not be worth repairing. Flag for owner decision.
